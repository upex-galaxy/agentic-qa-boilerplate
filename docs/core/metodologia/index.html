Metodología

Este repo aplica el IQL, el ciclo de calidad de UPEX Galaxy. Estas páginas resumen el método y explican qué skill del repo ejecuta cada stage.

La fuente oficial

El método se publica en upexgalaxy.com/metodologia (en inglés: /en/methodology). Si algo aquí no coincide con el sitio, manda el sitio.

Vista general

IQL

Tres fases, ocho stages, la escalera de artefactos y el contrato agéntico de cada stage.

Fase 1

Early-Game

Prevención: Shift-Left, Planning, Execution y Reporting, a cargo del QA Analyst.

 Fase 2

Mid-Game

Detección: Documentation y Automation, con el gate de ROI y la arquitectura KATA.

 Fase 3

Late-Game

Regression con veredicto GO / CAUTION / NO-GO y las métricas de producción.

 Sin skill todavía

Observation

Canary, RUM, chaos y SLO: el stage que el método declara y el repo aún no automatiza.
