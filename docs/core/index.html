Agregar páginas propias

  1. Crea una carpeta fuera de core/

    Por ejemplo docs/<equipo>/. El updater nunca escribe fuera de core/.

  2. Copia una página como punto de partida

    Cada página es un HTML con <title> y <meta name="description">, que enlaza docs/assets/docs.css y docs/assets/docs.js.

  3. Recarga el portal

    bun run docs arma el índice en cada recarga. El orden sale de <meta name="docs-order">, y un index.html con <meta name="docs-section-title"> le da nombre a la carpeta.
