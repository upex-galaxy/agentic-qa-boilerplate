# launch.txt: one self-contained line per worker
#
# Copy to the workflow skill's own session scope (for example
# .session/sprint-testing/sprint-<N>/launch.txt or .session/orchestration/<slug>/launch.txt).
# Owner: the conductor.
#
# RULES (see references/launch-seam.md):
#   1. Write this file always, with or without a runtime. The lines are for a human to paste and for
#      a terminal the conductor deliberately wants unsupervised. A supervised worker is launched
#      natively (agent, model and effort, no command line) and gets its prompt sent right after
#      readiness, because a custom-argv terminal can never be adopted.
#   2. The PROMPT is the payload both paths share, byte for byte. Do not paraphrase it.
#   3. Regenerate the file whole on each planning pass. Finished items drop out; nothing is edited in
#      place.
#   4. Each line is self-contained: it exports what the worker needs and starts the agent with the
#      full prompt.
#   5. Keep `"`, `<` and `>` out of the prompt. They break the shell parse, the terminal still
#      reports success, and nothing runs.
#   6. Validate before launching:  sh -n <this file>  (or the equivalent for the user's shell).
#   7. Lines starting with # are documentation. Strip them before a syntax check if the checker
#      objects, and never hand one to the launcher.
#   8. Every prompt OPENS with `/<workflow-skill> <label> fleet worker`, where <label> is the worker's
#      roster label, one token: [<KEY>-]<slug>, kebab-case, single hyphens inside (a ticket key plus a
#      slug, or a kebab slug such as volatile-impl). The slug has 3 or 4 words so the owner can read
#      it. The worker's NAME is <label>--<handle> (references/session-identity.md §2b): the identity
#      hook composes it on Claude Code from the token plus ORCA_TERMINAL_HANDLE, and the workflow
#      skill detects fleet mode from the token. A launch without the token leaves the tab titled
#      "worker-<task id>" and the session with a generated title. The prompt also carries the
#      continuation sentence: run every stage without returning to the prompt until worker_done is
#      sent. Both paths, every harness.
#   9. An environment prefix is at most a redundant signal on this path and never reaches a native
#      worker. Do not make fleet detection depend on it.
#  10. The permission flag matches orchestration.permission_modes.worker (.agents/project.yaml),
#      translated per harness in references/orca-machine-setup.md §3.1. The lines below carry the
#      shipped default, bypass. Flags were read 2026-10-28 at the versions named on each line;
#      confirm with `<harness> --help` on the machine before pasting.
#
# Claude Code (flags per code.claude.com/docs/en/cli-reference, read 2026-10-28). Use the full model
# id, never an alias, because an alias moves on its own. Bypass is --dangerously-skip-permissions
# (auto would be --permission-mode auto, which pauses and prompts after 3 consecutive or 20 total
# blocks). There is no name flag: --name marks the name as human-set and the hook then never appends
# the handle, so the hook names the session (<label>--<handle> inside an Orca terminal, <label> alone
# outside). The line starts the binary bare: no launch line loads .env into the worker's shell, and
# every MCP server and repo script loads it itself (references/provisioning.md §1b).
claude --model <full-model-id> --effort {{DEFAULT_EFFORT}} --dangerously-skip-permissions '/<workflow-skill> <label> fleet worker. Read <ABS>/.session/orchestration/<slug>/COMMON.md then <ABS>/.session/orchestration/<slug>/W-<label>.md and execute your brief. Run every stage without returning to the prompt until worker_done is sent; stage boundaries are not checkpoints. Channel: {{MESSAGE_VERB}}. No heartbeats. ROUTE-SCOPE: <section ids>'

# Per-issue brief, the sprint shape (one line, still self-contained). A sprint-testing worker's label
# is the bare issue key, because that skill reads the issue it owns from the token; its name is
# <KEY>--<handle>. Fleet mode is detected from the prompt token and the brief, never from an
# environment prefix: a prefix never reaches a native supervised worker and was measured empty on a
# real fleet even on this path.
claude --model <full-model-id> --effort {{DEFAULT_EFFORT}} --dangerously-skip-permissions '/sprint-testing <KEY> fleet worker. Read <ABS>/.session/sprint-testing/sprint-<N>/<KEY>/brief.md and execute it. Run every stage without returning to the prompt until worker_done is sent; stage boundaries are not checkpoints. Channel: {{MESSAGE_VERB}}. No heartbeats. ROUTE-SCOPE: <section ids>'

# The same prompt, delivered on the supervised path (no argv, so no name flag, no permission flag and
# no prefix: the mode comes from the app's per-agent default arguments, orca-machine-setup.md §3.1):
#   1. launch natively:  [ORCHESTRATION_TOOL] worker-start: task + worktree + agent + model + effort
#   2. read the handle:  [ORCHESTRATION_TOOL] worker-list: agentTerminalHandle (gotcha G78)
#   3. read the screen:  status footer present, permission mode = orchestration.permission_modes.worker,
#                        and credentials loaded (MCP servers connected), or fix it before any work
#   4. send the prompt:  [ORCHESTRATION_TOOL] terminal send, the text between the quotes above
#   5. name it:          the worker renames its own tab to <label>--<handle> as its first action; the
#                        conductor re-issues [ORCHESTRATION_TOOL] terminal rename with the same title
#                        in every sweep; on Codex and an OpenCode whose `/rename` takes an argument also terminal send the rename
#                        verb ('/rename <label>--<handle>')
#   6. read it back:     read the tab title and the session name off the screen. A tab still reading
#                        "worker-<task id>" or a generated session title means the token was missing:
#                        rename now and fix the line before the next launch.

# OpenCode (v1.19.5 / v2.2.0; opencode.ai/docs/cli and /docs/permissions, read 2026-10-28): -m/--model,
# --agent, --prompt, --auto (bypass: auto-approve every permission not explicitly denied; hidden
# aliases --yolo, --dangerously-skip-permissions), -s/--session, -c/--continue, --fork. There is no
# name flag and no effort flag. Once the session is up, type '/rename <label>--<handle>' into it on
# v2.2; on v1 /rename opens a dialog with no argument, so the roster carries the name (a model cannot
# rename its own session).
opencode --model <provider/model> --auto --prompt '/<workflow-skill> <label> fleet worker. Read <ABS>/.session/orchestration/<slug>/COMMON.md then <ABS>/.session/orchestration/<slug>/W-<label>.md and execute your brief. Run every stage without returning to the prompt until worker_done is sent; stage boundaries are not checkpoints. Channel: {{MESSAGE_VERB}}. No heartbeats. ROUTE-SCOPE: <section ids>'

# Pi (v1.4.0 and v1.5.0, measured 2026-11-04, ADR-0026): there is no approval system, so bypass needs
# nothing; --approve skips the project-trust prompt for this run. No -n: the adapter names the session
